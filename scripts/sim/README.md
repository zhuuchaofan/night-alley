# 夜巷 (Night Alley) 无头数值模拟器

用于在无浏览器 / 无 Phaser 环境下批量跑 180 秒单局生存模拟，评估当前数值曲线与通关压力。

## 引擎机制与还原度

- 引擎位于 [`scripts/sim/sim.ts`](./sim.ts)，直接复用 [`src/game/balance.ts`](../../src/game/balance.ts) 与 [`src/game/choices.ts`](../../src/game/choices.ts) 的全部常量、公式与三选一池，不复制数值。
- 固定时间步长 `dt = 1 / 30`（30 Hz），单局上限 `ROUND_DURATION_SECONDS = 180s`（5400 tick）。
- 严格镜像 `src/scenes/GameScene.ts` 的逻辑顺序与数值：
  - 刷怪间隔 `spawnIntervalAt`、怪物属性 `enemyStatsAt`、同场普通怪上限 `MAX_ENEMIES = 65`（Boss 不占名额）、四边 `SPAWN_MARGIN = 30` 出生。
  - 敌人直线追击玩家；接触伤害 `2`、每怪独立 `0.5s` 冷却、触碰距离 `PLAYER_RADIUS (12) + ENEMY_RADIUS (10) = 22`。
  - 三武器逻辑与冷却：桃木剑（0.8s / 范围 90 / 弧度 100° / 伤害 6）、铜钱镖（1.2s / 范围 320 / 伤害 5 / 弹速 420 / 命中半径 5+10）、灯笼火（2.0s 冷却 / 持续 2.0s / 每 0.5s 一跳 / 每跳 1.5 / 范围 90；解锁瞬间立即激活首轮持续时间）。
  - 杀敌掉落 1 颗经验珠；`pickupRadius` 内以 `420` 速度吸附，进入 `18` 距离拾取并按 `xpNeededForLevel` 升级；升级用 `generateChoices(stats, rng)` 抽三张并瞬间完成选择（等价于真实游戏升级弹窗暂停计时）。
- **敌人推离实现选择**：采用 **48px 均匀空间网格（Uniform Spatial Grid）** 精确实现与 `GameScene.ts` 相同的按怪半径之和最小间距两两推离，而非“同时接触攻击者上限 6 只”的近似。原因：`CELL_SIZE = 48` 覆盖最大的 Boss+Boss 间距（`24 + 24`），遍历 3×3 邻格即可在 $O(n)$ 平均复杂度内完整覆盖所有间距小于半径之和的怪物对，且预分配 `Int16Array` 链表保证零每帧内存分配，既保持数值完全保真又兼顾 200 局批跑速度。

## 模拟策略（典型玩家行为）

### 走位策略（风筝）

1. **危险感知与拉扯**：扫描场上敌人，对 `200px` 内的所有敌人按距离平方反比（`1 / max(dist, 8)^2`）累加逃离向量；在可活动边界（`x ∈ [12, 948]`，`y ∈ [56, 528]`，避开顶部 `44px` HUD）`60px` 内加入轻度墙体斥力，防止风筝时顶死角落。
2. **Boss 优先躲避**：Boss 按半倍有效距离计入上述感知（即触发范围与逃离权重均为普通怪 2 倍），模拟真人看到大怪会特意保持距离。
3. **近身优先逃生**：若 `120px` 内存在任意敌人，直接沿逃离向量全速（`stats.speed`）走位。
4. **安全期拾珠与回中**：若 `120px` 内无敌人，优先向 `300px` 内最近的经验珠移动；若附近无珠，则向场地中心 `(480, 292)` 漂移。若 `120–200px` 内仍有敌人，则将 `0.5 × 逃离方向` 与目标方向合成。

### 升级三选一策略

使用 `generateChoices(stats, rng)` 抽出 3 张后，按以下固定优先级选择：

1. 新武器 **铜钱镖**（`new:coin_dart`）
2. 新武器 **灯笼火**（`new:lantern_fire`）
3. **桃木剑**伤害升级（`upg:peach_sword:damage`）
4. 其他已有武器的**伤害升级**（优先取当前等级最低者：`upg:coin_dart:damage` / `upg:lantern_fire:damage`）
5. 铜钱镖数量 +1（`upg:coin_dart:count`）
6. 灯笼火范围 +30%（`upg:lantern_fire:range`）
7. 全局伤害 +20%（`stat:damage`）
8. 血量低于上限 50% 时优先选血量上限 +10 并回血 10（`stat:hp`）
9. 桃木剑攻速 +20%（`upg:peach_sword:speed`，兜底项）
10. 移速 +15%（`stat:speed`）
11. 拾取范围 +40%（`stat:pickup`）
12. 血量 $\ge 50\%$ 时的固本养神（`stat:hp`，兜底项）

## 运行方式

> 说明：由于 `src/game/choices.ts` 对仅类型符号未使用 `import type`，Node 24 原生类型剥离会报导出缺失错误；遵循不修改 `src/` 与不新增依赖约束，`npm run sim` 使用仓库内置的 `rolldown` 将 TS 打包至 `node_modules/.cache/night-alley-sim.mjs` 后执行。

```bash
# 默认运行 200 局，seed=1
npm run sim

# 自定义局数与随机种子
npm run sim -- --runs 50 --seed 42
```

CLI 永远以退出码 `0` 结束，仅向 stdout 输出统计汇总与每 10 秒平均血量轨迹。

## 调后结果（fun-01：难度曲线重调 + 150 秒终局 Boss）

- **调参定稿**（`npm run sim`，200 runs, seed=1, dt=1/30；seed=42 复核通关率 53.0%）：
  - 刷怪间隔 / 怪物血量步长 / 怪物移速加成：**保持基线不变**（`max(0.35, 1.2 - 0.004 * t)`、`ENEMY_HP_STEP_SECONDS = 30`、`ENEMY_SPEED_MAX_BONUS = 0.4`）。sim 灵敏度实测：斜率 0.004→0.0045、血量步长 30→28、移速加成 0.4→0.45 任一单改都把通关率打到 39–42%（跌破 50% 下限），说明原曲线已在胜负悬崖边，再陡必崩；压力改由终局 Boss 提供。
  - 同场普通怪上限：`MAX_ENEMIES = 60 → 65`（100 局实测对通关率无影响：58.0% → 58.0%，只给 Boss 阶段留出人群余量）。
  - 终局 Boss（`150s` 刷出，不受 `MAX_ENEMIES` 约束）：HP `120`、移速 `85`、接触伤害 `4`、攻击间隔 `1.75s`、半径 `24`、击杀掉 `20` 颗经验珠。定稿过程：初版 Boss（260 HP / 105 移速 / 6 伤 / 0.5s 间隔）+ 陡曲线 = 通关率 0.0%；诊断证明 Boss 接触伤害是唯一致死通道（接触伤害置 0 时通关率回到 71.0%，与无 Boss 基线 71.5% 相同）；遂把单次接触伤害留在 4（仍为普通怪 2 倍）、攻击间隔拉到 1.75s、血量降到 120（约 43% 到达 Boss 的局能打死它）。
  - 走位策略补丁：sim 玩家对 Boss 按半倍有效距离躲（见上文“Boss-aware”），模拟真人看到大怪会特意保持距离；无此补丁时同数值通关率只有 30.0%。
