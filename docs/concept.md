# 《夜巷》一页纸概念 v0.1（2026-11-27）

## 一句话概念

1987 年老街的夜巷里，你是守夜的学徒，手里一把桃木剑，在成群的心魔和夜行物中活到天亮——边走边打，越打越强。

## 核心循环（动词环）

走位 → 自动攻击 → 杀敌掉经验 → 升级三选一 → 更强 → 撑住下一波更密的敌人 → 活到天亮

## 玩家每分钟在干什么

- 唯一主动操作是**移动**（WASD/方向键，手机上拖动）。攻击全自动，打最近的敌人。
- 每升一级弹**三选一**：新武器 / 武器变强 / 移速、血量、拾取范围等属性。这是全游戏唯一的决策点，必须每次都有犹豫。
- 敌人从四面八方围上来，越往后越密、越快、越硬。玩家在“聚怪一波清”和“被包围”之间走钢丝。

## 第一分钟

进巷子，脚下只有一把自动挥砍的桃木剑。几个慢悠悠的纸人影从暗处走来，砍倒掉经验珠，捡满升一级，三选一里出现第二把武器（铜钱镖），立刻感觉清怪快了一截。第 1 分钟结束时，屏幕上的敌人明显变多——玩家已经知道这游戏要什么了。

## 胜负与一局时长

- 一局 3 分钟（原型档）：胜利有两条路——撑到天亮，或在天亮前打死大心魔（心魔已除，直接胜利结算）；血条见底 = 败。
- 结算只给四行：存活时间、杀敌数、等级、最高同时在场敌人数。死了立刻能重开。

## 验证标准（第一周回答“好玩吗”）

- 制作人不经讲解，能玩满 3 分钟；
- 死了想立刻重开（而不是“哦，结束了”）；
- 升级三选一时有犹豫，选完立刻想验证选得对不对。

三条里两条不满足，改循环，不加内容。

## 世界观与人物（草案，待制作人定）

- 同一个 1987 老街：当铺那条街的背巷。白天当铺收旧物，夜里没赎走的旧物心魔化形出来游荡。
- 玩家：掌柜出门后留守的学徒，守夜是考验的一部分。
- 敌人：纸人影、旧物化形（算盘珠、铜钱、灯笼火），先用剪影和色块，不画细。
- 武器（原型 3 把）：桃木剑（近战挥砍）、铜钱镖（自动射最近敌）、灯笼火（周期灼烧周围）。

## 技术与复用

- Phaser 3.90.0 + TypeScript + Vite + Vitest + Playwright，与当铺同一套；GitHub Pages 部署，`base: './'`。
- 复用：16 色板、像素字库、sim 调数值的办法、审查门流程。美术、音效、字库细节后加，原型期全用色块和系统字。

## 纸面原型（先在纸上跑一轮）

- 棋盘格当巷子，玩家一枚棋子，敌人棋子每回合向玩家走一格；
- 玩家不动手攻击，武器自动打最近一格的敌人；
- 杀 3 个敌人升一级，从三张卡里挑一张（新武器/伤害+/移速+）；
- 3 轮下来还想继续，循环成立。

## 本原型范围

- 做：移动、自动攻击、敌人刷新与围攻、经验与升级三选一、血量与计时、胜负结算与重开。
- 不做：局外成长、第二张图、美术、存档、多武器合成。（终局 Boss 由“更好玩阶段 1”加入，合成音效由“更好玩阶段 5”加入，见下节。）

## 更好玩阶段 1

- 难度曲线目标：前 30 秒保持可上手（30 秒平均血量 ≥ 22），3 分钟内压力持续上升，典型打法通关率目标 50–70%。
- 终局 Boss 规则：开局满 150 秒（HUD 倒计时剩 00:30）从随机边缘现身一只大心魔（不受同场怪上限约束）；打死大心魔进入死亡演出——世界以 0.25 倍速慢动作 1.4 秒、大心魔碎裂成 18 块翻滚的碎片——然后胜利结算（心魔已除），撑到 03:00 天亮同样胜利。Boss 不再掉落经验珠。
- 击杀碎裂：任何敌人死亡时都碎成翻滚的像素碎片（小怪 7 块小碎裂、精英 12 块、大心魔 18 块大碎片，碎片更大、飞得更远、留得更久）；碎片带旋转、随速度衰减、渐隐。
- 定稿数值（sim 实测）：刷怪/血量/移速曲线保持基线不变（sim 证明任一单项加陡都把通关率打到 39–42%），同场上限 60→65；Boss：血量 120、移速 85、接触伤害 4、攻击间隔 1.75 秒、半径 24。200 局实测通关率 53.5%（seed=42 复核 53.0%），Boss 击杀率 36.0%。

## 更好玩阶段 3

- 武器进化规则：任一已持有武器升至 **5 级**且尚未进化时，该武器在升级三选一池中的 2 张常规升级卡会替换为 1 张**金边进化卡**；每把武器每局（一生）只进化一次。进化不改变武器等级，选中后立即生效并切换为进化名称与强化视觉；进化完成后恢复该武器的常规升级卡，可继续升级。
- 进化名称与定稿加成（`EVOLUTION_DEFS`）：
  - 桃木剑 → **破魔法剑**：伤害 ×2，挥砍弧形 +40°（100°→140°）
  - 铜钱镖 → **九连钱镖**：数量 +2，伤害 ×1.5
  - 灯笼火 → **照夜魂灯**：伤害 ×2，灼烧范围 ×1.5
- sim 实测（200 局，seed=1，升级策略优先选进化卡并继续投已进化武器）：
  - 通关率 **53.0%**（seed=42 复核 **53.5%**），平均存活 158.91 秒，平均等级 8.90，平均杀敌 179.47，Boss 击杀率 **39.5%**（79/200）。
  - 至少进化一把武器占比 **12.5%**（25/200）；各武器进化达成率：破魔法剑 **8.5%**、九连钱镖 **2.5%**、照夜魂灯 **1.5%**。
  - 进化路线分布：无进化 175 局（87.5%） / 仅剑 17 局（8.5%） / 仅镖 5 局（2.5%） / 仅火 3 局（1.5%） / 两把 0 局（0.0%） / 三把 0 局（0.0%）。

## 更好玩阶段 4

- 新增三种敌人（`kind`：`swift` / `shooter` / `elite`，保留原有 `paper` / `lantern` / `boss`；名称全部选用像素字库内字形）：
  - **疾纸人**（`swift`）：移速为普通怪 ×1.5，血量固定 2（一刀清）、半径 8、接触伤害 2、攻击间隔 0.5 秒；从边缘高速扑来，考验反应与扇形清理。
  - **远灯笼**（`shooter`）：移速为普通怪 ×0.8，血量与普通怪相同、半径 10；距离 > 200px 时靠近，≤ 200px 停步，被近身 < 120px 时后撤拉开至约 200px；每 3.0 秒向玩家发射 1 发慢速火球弹（弹速 110、半径 5、伤害 1，出界销毁），迫使玩家横向走位躲弹或主动追击。
  - **大魔面**（`elite`）：血量为普通怪 ×4.5（向下取整）、移速为普通怪 ×0.85、半径 14、接触伤害 2、攻击间隔 0.5 秒、显示尺寸 88×88 与 36px 血条；击杀掉落 3 颗经验珠，作为高血量压迫目标。
- 出场节奏（`pickSpawnKind(elapsedSeconds, rng01)`，Boss 夜 150 秒后照常沿用此池，Boss 规则与 65 上限不变）：
  - `elite` 全程稀有权重 **0.8%**；
  - `swift` 0 秒时 0%，线性增至 120 秒 **25%** 并保持；
  - `shooter` 30 秒前 0%，30→120 秒线性增至 **15%** 并保持；
  - 剩余权重按原比例分给 `paper`（2/3）与 `lantern`（1/3）。
- sim 实测（200 局，含飞行敌弹横向躲避 AI）：

| 指标 | 200 局（seed=1） | 200 局（seed=42） |
| --- | --- | --- |
| 通关率 | 55.0% | 51.5% |
| 平均存活 | 155.18s | 151.47s |
| 平均杀敌 | 167.19 | 161.84 |
| 平均等级 | 8.38 | 8.20 |
| 平均精英出现数 | 1.74 / 局 | 1.50 / 局 |
| 击杀占比（paper / lantern / swift / shooter / elite / boss） | 50.3% / 24.8% / 19.3% / 4.6% / 0.8% / 0.2% | 50.5% / 25.2% / 18.9% / 4.4% / 0.7% / 0.3% |
| Boss 击杀率 | 41.5% | 41.0% |

## 更好玩阶段 5

- **合成音效**：纯 WebAudio 实时合成 5 种效果音（挥剑、受击、击杀、升级、大心魔现身），受击与击杀各自独立 120ms 节流；标题页右上角提供会话级静音按钮（`#sound-toggle`），开局手势解锁音频。
- **默认横屏与竖屏提示**：粗指针竖屏自动显示「横屏体验更佳」提示，手机端点击开始守夜时请求全屏并锁定横屏（不支持或拒绝时静默回退继续游玩）。
- **虚拟摇杆视觉升级**：保持 50/7/14 CSS px 手感、跟手底盘与左手半区触发不变，绘制双层同心环、中心死区点、按压缩放与摇杆帽内方向箭头。
- **怪物图册**：新增独立 `BestiaryScene`，收录全部 6 种敌人（心魔、灯笼、疾纸人、远灯笼、大魔面、大心魔），展示开局数值、机制说明及本局按种类击杀计数（标题页进入显示未开局，结算页进入显示本局战绩）。
